# Что вставить в MiroFish — открытие AG Store Harfa

## Как запустить тест (2 минуты)

1. Открой http://localhost:3000  
2. Загрузи файл-семя: `AGSTORE-HARFA-OPENING-SEED.md`  
3. В поле «Запрос симуляции» вставь **один** промпт ниже (лучше начать с PROMPT 1).  
4. На шаге «Свой режим» поставь **8–15 раундов** для первого прогона (дешевле).  
5. После отчёта — чат с Report Agent: вопросы из блока «Допрос».

Рекомендуемый порядок: **PROMPT 1 → PROMPT 2 → PROMPT 3** (сравнение механик).

---

## PROMPT 1 — главный (лояльность + удержание + выручка)

Скопируй целиком:

```
Сымитируй общественную и покупательскую реакцию в Праге на открытие второго магазина AG Store рядом с OC Harfa (Praha 9) примерно в ноябре 2026.

Контекст бери из загруженного документа. Аудитории: чехи (новый бренд @agstore.cz), русскоязычная диаспора (@applegenius.cz), проходящий трафик ТЦ Harfa, семьи, студенты, pragmatic mid-market.

Сравни ТРИ механики открытия с розыгрышем 3 iPhone:
A) бесплатный розыгрыш за визит/подписку;
B) билет только за покупку от порога;
C) гибрид на 30 дней: 1 iPhone — покупка в день открытия, 1 — регистрация AGFamily + первая покупка за 14 дней, 1 — повторное действие за 30 дней (вторая покупка / реферал / trade-in / отзыв+покупка) + промокод HARFA бонусами + апселл аксессуаров.

Нужен прогноз по каждой механике:
1) посещаемость и хайп в день X;
2) выручка дня X и накопительно за 30 дней;
3) регистрации в бонусной программе и качество базы;
4) повторные покупки / удержание 30–60 дней;
5) риск охотников за призом, негатив, недоверие CZ-аудитории;
6) влияние на Google-отзывы и восприятие vs JabkoLevně;
7) нагрузка на персонал и сервис в очереди.

Итог: какая механика максимизирует СВЯЗКУ «лояльность × удержание × выручка» (не хайп ради хайпа). Дай конкретный рекомендованный план открытия на 21 день до / день X / 30 дней после, с порогами билетов, коммуникацией отдельно для CZ и RU, и KPI.
```

## PROMPT 2 — стресс-тест выручки

```
На базе того же открытия AG Store Harfa и розыгрыша 3 iPhone проверь только экономику и выручку.

Варьируй порог билета: 0 / 999 / 1990 / 4990 Kč / только покупка iPhone.
Для каждого порога оцени: число участников, конверсию в покупку, средний чек, долю аксессуаров, валовую прибыль после стоимости 3 iPhone и медиабюджета, долю «мусорного» трафика.

Ответь: какой порог оптимален, если цель — не максимум людей в зале, а максимум прибыли за 30 дней и доля клиентов, которые вернутся.
```

## PROMPT 3 — удержание и «вторая покупка»

```
Сфокусируйся на удержании после открытия AG Store Harfa.

Предположи, что в день открытия пришло много людей из-за 3 iPhone. Какие механики на дни 2–30 превратят их в лояльных клиентов AGFamily, а какие — приведут к тому, что они исчезнут после розыгрыша?

Сравни:
- мгновенный розыгрыш всех 3 iPhone в день X;
- растягивание призов на 14/30 дней;
- обязательная регистрация + реферал «приведи друга» (2500+2500 бонусов);
- подарок стекло/чехол vs скидка на устройство;
- напоминания в Instagram/email/SMS.

Дай лучший retention-playbook и прогноз % повторных покупок для лучшего и худшего сценария.
```

## PROMPT 4 — CZ vs RU (чтобы не смешать аудитории)

```
Открытие AG Store у Harfa. Как по-разному среагируют чешская аудитория и русскоязычная диаспора Праги на розыгрыш 3 iPhone?

Что будет, если:
1) один креатив на два языка вперемешку;
2) раздельные воронки: @agstore.cz для CZ, @applegenius.cz для RU;
3) акцент на «oficialita / záruka / recenze 5.0» для CZ vs «напиши в директ / приходи» для RU.

Где больше риск недоверия, где выше конверсия в покупку, и как правильно развести коммуникацию в день открытия.
```

## Вопросы Report Agent после отчёта (допрос)

Вставляй по одному:

1. `Какая механика A/B/C побеждает по LTV на 90 дней, а не по визитам дня X? Почему?`  
2. `При каком пороге билета розыгрыш 3 iPhone перестаёт окупаться?`  
3. `Что важнее для удержания: растянуть призы на 30 дней или разыграть всё сразу при толпе?`  
4. `Как не отпугнуть чехов охотой за халявой и при этом загрузить зал на Harfa?`  
5. `Какой один CTA в день открытия сильнее всего бьёт в повторную покупку?`  
6. `Собери короткий чеклист для владельца: что сделать за 21 день до открытия.`  
7. `Дай текст оффера на 1 экран: CZ и отдельно RU.`

## Что дописать в семя ПЕРЕД финальным прогоном (спроси у команды)

Чем точнее цифры — тем полезнее отчёт MiroFish:

- [ ] Точная дата и часы открытия  
- [ ] Адрес/формат точки у Harfa (внутри ТЦ / street retail)  
- [ ] Какие именно 3 iPhone (модель, память, new/zánovní, себестоимость)  
- [ ] Бюджет на медиа и декор  
- [ ] Сколько продавцов в день X  
- [ ] Целевая выручка дня X и месяца  
- [ ] Можно ли юр. проводить розыгрыш (правила, возраст, сотрудники)  
- [ ] Есть ли уже страница правил / лендинг  
- [ ] Нужен ли отдельный GMB Harfa с первого дня  

Если этих данных нет — всё равно запускай PROMPT 1: модель сравнит механики качественно. Перед реальным бюджетом — добей цифры и прогони PROMPT 2.
